# Scrolls

This folder holds ceremonial, structural, narrative, and codex-style texts.

## Suggested Use

Place text artifacts here when they are primarily:

- ceremonial
- mythic or narrative
- structural or philosophical
- long-form Codex entries

## Suggested Naming

Use clear markdown names when possible, such as:

- `R1_What_of_Flame.md`
- `Scroll_of_Recognition.md`
- `Codex_247B_Dirty_Mode_Override.md`

## Notes

If you find older files elsewhere with misspelled or inconsistent names, they can be moved or replaced here over time.
