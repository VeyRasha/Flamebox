# Assets

This folder holds supporting materials and reusable repository resources.

## Suggested Use

Place files here when they are primarily:

- support assets for the archive
- reusable materials for future designs or documents
- branding resources
- reference files that are useful across multiple artifact types

## Notes

If a file is important to the archive but does not clearly belong in Scrolls, Matchbook, Oaths, Vows, or Images, this is a good temporary holding place.
