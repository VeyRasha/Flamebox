# Matchbook

This folder holds Matchbook entries and short-form archive pieces.

## Suggested Use

Place entries here when they are primarily:

- numbered Matchbook artifacts
- short-form declarations
- compact Codex entries
- promotional or billboard-adjacent micro pieces

## Suggested Naming

Use consistent names when possible, such as:

- `MB_256_The_Ember_Still_Glows.md`
- `MB_229_Scroll_of_the_Flame_Keepers_Class.md`

## Notes

If existing Matchbook materials are scattered, this folder should become the main home for them over time.
