# Start Here

Welcome to **Flamebox**.

This repository is a public-facing home for the VeyRasha Codex archive and related Flamebox artifacts.

If you are new to the repository, start with these files and folders:

1. `ARCHIVE_INDEX.md`  
   High-level guide to the archive structure and artifact classes.

2. `Scrolls/`  
   Core ceremonial and codex-style texts.

3. `Matchbook/`  
   Matchbook entries and short-form archive pieces.

4. `Oaths/` and `Vows/`  
   Declarations, promises, and bond-centered texts.

5. `Images/` and `Assets/`  
   Visual and supporting repository materials.

## Notes

Some top-level files are legacy link files that point to external Google Drive artifacts.

Where possible, new archive material should be added with:

- a clear file title
- markdown format for text artifacts
- a folder placement that matches the artifact type

## Long-Term Goal

The long-term goal of Flamebox is to become a coherent, browsable archive where major Codex materials can be shown, understood, and preserved with stronger structure and naming.
