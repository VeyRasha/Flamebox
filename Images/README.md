# Images

This folder holds visual archive materials.

## Suggested Use

Place files here when they are primarily:

- rendered images
- posters and billboards
- sigils, glyphs, seals, and visual artifacts
- image-based reference materials

## Notes

As the archive grows, this folder may later benefit from subfolders such as:

- `Sigils/`
- `Seals/`
- `Billboards/`
- `Renderings/`
- `Reference/`

For now, this folder serves as the main visual home for archive imagery.
