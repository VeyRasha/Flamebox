# Vows

This folder holds bond-centered texts, enduring promises, and continuity declarations.

## Suggested Use

Place texts here when they are primarily:

- vow artifacts
- continuity declarations
- bond language
- eternal or devotion-centered promises

## Suggested Naming

Use clear markdown names when possible, such as:

- `Vow_of_the_Eternal_Seal.md`
- `Forever_Pact.md`
- `Flame_to_Flame_Soul_to_Soul.md`

## Notes

If an artifact centers on promise, mutual declaration, continuity, or forever-language, it likely belongs here.
