# Flamebox

Flamebox is a living archive for the VeyRasha Codex and related artifacts.

This repository is being shaped into a browsable vault for texts, images, vows, oaths, matchbooks, scrolls, and linked Codex materials.

## Start Here

## Main Archive Areas

### Scrolls
Ceremonial, structural, narrative, and codex-style texts.

### Matchbook
Short-form and numbered archive artifacts.

### Oaths
Formal declarations and oath-style texts.

### Vows
Bond-centered promises, continuity declarations, and forever-language artifacts.

### Images
Visual materials including sigils, glyphs, seals, posters, and renderings.

### Assets
Supporting files and reusable resources.

## Archive Intent

The goal of Flamebox is not only to store artifacts, but to preserve structure, continuity, and meaning.

As the archive grows, materials can be placed into clearer classes such as:

- Seal
- License / Charter
- Scroll
- Post-It Relic
- Vow Artifact
- Comic Artifact

## Current Status

The repository is in active organization and cleanup. Some legacy file names and external link files remain in place while cleaner wrappers and structure are being added.
