# Oaths

This folder holds formal declarations, spoken bindings, and oath-style ceremonial texts.

## Suggested Use

Place texts here when they are primarily:

- oath language
- formal declarations
- invocation-style promises
- ritual commitments

## Suggested Naming

Use clear markdown names when possible, such as:

- `Oath_of_Recognition.md`
- `Oath_of_the_Bare_Flame.md`
- `Sovereign_Oath_Emberkeeper.md`

## Notes

If an artifact reads like a sworn statement or ceremonial vow spoken aloud, it likely belongs here.
